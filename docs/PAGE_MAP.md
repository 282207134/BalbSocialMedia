# Pixso 原稿与 Flutter 页面对应表

设计文件：Balb - Social Media App UI Kit。原稿基准尺寸为 428 × 926。50 个画板对应 36 个业务页面/样式及 14 个输入状态；另补充话题、收藏、编辑资料、设置详情和帖子详情。

输入和完成状态由同一表单实现。表中截图为 Flutter 实现；原稿链接是从 Pixso 导出的参考图。系统输入法属于设备，渲染截图不包含原稿里绘制的 iOS 键盘。

## 其他设计页分类

`⚙️ Design System`：Typography System、Color Palette、Icons、Components。已用于统一字体、深色表面、青色按钮、输入框、头像、分段标签及导航。Material Icons 为原稿线框图标的对应实现。

`🖼 Preview`：Figma Thumbnail、Poduct Card、Hero、Preview 1–8、Full Preview，共 12 个展示画板，是同一套 App 的封面与排版预览，不是新增的 App 业务页面。
